# 飞泉SCM系统项目说明与操作手册

## 1. 系统简介

飞泉SCM系统是面向中小制造企业的供应链管理系统，覆盖供应商管理、采购执行（请购 / 询价 / 订单 / 收货质检）、仓储库存（批次台账 / 调拨 / 盘点）与结算付款（三单匹配 / 应付账龄）四条主线，并提供 API Key / Webhook / 增量同步三条开放集成通道。

- 技术形态：Python 标准库 + SQLite，单机可跑、零依赖；前端原生 JS，浏览器直接访问。
- 演示地址：https://drone-store.app.workbuddy.host/
- 代码仓库：https://github.com/dukema81/feiquan-scm

## 2. 启动与登录

### 2.1 本地启动

```bash
cd feiquan-scm
python backend/server.py          # 默认 http://127.0.0.1:8019
```

## 3. 界面骨架

- **顶部标题栏**：公司名 / 账套（FQ-SCM-2026）/ 版本 / 退出。
- **菜单栏**：总览 / 主数据 / 采购执行 / 库存 / 结算与分析 / 系统 六组。
- **左侧导航树**：14 个页面入口，待办数以角标提示（如请购待审批数、库存缺料数）。
- **主工作区**：KPI 卡片 + 筛选 chips + 数据表 + 图表；点行进详情弹层。
- **右侧侧栏**：随页面切换的口径说明与预警清单。
- **底部状态栏**：当前操作员 / 在途采购 / 本月到货 / 操作结果提示。

## 4. 逐页操作说明

### 4.1 供应链驾驶舱

六张 KPI（在途采购 / 本月到货 / 库存金额 / 缺料预警 / 待处理发票 / 供应商与物料），采购订单流程分布、近 6 个月采购趋势、待办清单、缺料与补货建议；侧栏展示资质预警与业务规则现状。

### 4.2 供应商档案

- 顶部状态 chips（待准入 / 已准入 / 观察 / 冻结）+ 等级筛选 + 关键字。
- 「+ 新建供应商」：录入名称时系统自动查重（同名相似提示）。
- 点行进入 **360 弹层**，五个标签：资质 / 绩效 / 订单 / 收货 / 发票；可在此登记资质、录入绩效（四维比率）、执行准入或冻结。
- 准入闸口：至少登记 1 项资质；资质过期自动冻结。

### 4.3 物料主数据

- ABC chips 筛选；新建时编码唯一校验 + 名称查重。
- 「重算 ABC」按年耗用金额重分档。
- 点行进详情弹层：价格记录 / 分仓库存 / 出入库流水。

### 4.4 请购单

- 「+ 新建请购」：部门 / 需求日期 / 用途 + 多行明细（物料、数量、估价自动带出标准价）。
- 状态机：草稿 → 提交（金额 ≤5000 自动通过）→ 待审批 → 批准 / 驳回 → 转订单 / 发起询价。
- 批准校验部门季度预算，超执行率给出拦截。

### 4.5 询价比价

- 点询价单看报价对比（最低价标注 + 价差）；「登记报价」按供应商录总价与交期（同商重复登记即更新）。
- 「定标」选择供应商自动生成采购订单并按标准价占比分摊明细单价；至少 2 家报价才能定标。

### 4.6 采购订单

- 列表含到货进度条、只看逾期开关；点行进详情：明细、收货单、**闸口缺失清单**（如「需采购总监审批」「供应商未通过准入」）与三单匹配提示。
- 「推进」按状态机给出可推进目标；「已结算」仅财务可推。
- 「到货登记」录入各明细收货量与批次效期，过账后自动推进部分 / 全部到货。

### 4.7 收货质检

- 待质检收货单 → 「质检」弹层逐行录合格 / 不良 / 批次 / 效期 → 结论自动判定（合格 / 让步接收 / 退货）。
- 「入库过账」把合格品写入库存并产生采购入库流水；「退货」留痕处理不良。

### 4.8 库存台账

- KPI：库存金额 / 缺料低库存 / 补货建议金额 / 健康度。
- 双视图：**物料汇总**（现存量 / 可用 / 安全库存 / 补货点 / 覆盖天数）与**批次明细**（仓库 / 批次 / 库龄 / 效期）。
- 状态 chips（缺货 / 待补货 / 低于安全库存 / 超储）与「只看近效期」筛选；点物料看分仓批次明细。
- 缺料建议表支持「按建议生成请购」，勾选物料自动带建议数量生成请购草稿。

### 4.9 库存作业

四个标签：

- **出入库流水**：全部收发存记录（采购入库 / 领用出库 / 调拨 / 盘盈亏），按类型 chips 过滤。
- **仓间调拨**：新建（调出 / 调入仓 + 明细）→ 审批 → 执行；执行时校验调出仓库存并写两条流水。
- **库存盘点**：按仓库发起（自动快照全部批次）→ 「录入实盘」逐行改实盘数 → 完成后差异行自动写盘盈 / 盘亏并调库存。
- **库存调整**：盘盈 / 盘亏 / 领用出库 / 其他入库四种手工过账入口。

### 4.10 结算付款

- 发票列表：匹配结果 / 差异率 / 到期日 / 逾期天数；状态 chips（待匹配 / 待付款 / 已付款 / 差异挂起）。
- 「登记发票」选订单自动带收货金额，登记即三单匹配（容差 2%）。
- 「三单对照」弹层并列订单金额 / 收货金额 / 发票金额与差异率。
- 匹配未通过禁止付款；付款支持部分付款；应付账龄五档柱图 + 明细。

### 4.11 报表分析

九模块：综合 KPI、采购趋势（6 月）、物料类别结构、供应商绩效 TOP10（含准时率）、库存周转、缺料清单、到货准时率（按月）、重点物料价格波动、应付账龄。侧栏附口径说明。

### 4.12 集成中心（仅管理员）

五标签：API Key（生成即展示明文一次 / 吊销）、Webhook（订阅 23 种事件 / 测试 / 编辑 / 删除）、投递记录（查看 / 重投）、外部映射（绑定外部 ID）、变更流（游标式增量拉取演示）。非管理员进入显示权限锁定页与对接指引。

### 4.13 基础设置

业务规则 8 条（管理员可启停 / 调阈值，立即生效并写日志）、仓库网络、部门季度预算、用户与角色。

### 4.14 操作日志

全部写操作留痕（操作员 / 动作 / 详情 / 时间），近 200 条。

## 5. 常见问题

**Q：订单推进按钮点了没反应？**
A：查看详情弹层的「闸口缺失清单」，缺什么补什么（审批、供应商准入、收货、发票匹配）。

**Q：发票付款被拒绝？**
A：三单匹配未通过（差异率 >2%）。先核对收货金额，或在设置中调整匹配容差后「重新匹配」。

**Q：调拨执行失败？**
A：调出仓库存不足，任一明细不足则整单失败（不做部分过账）。先盘点或调整后再执行。

**Q：供应商被冻结了？**
A：资质过期自动冻结。在供应商 360 → 资质标签补登新证后重新准入。

**Q：集成中心看不到？**
A：仅管理员可见。对接方使用管理员分配的 API Key 调用开放接口即可，无需进入界面。

**Q：如何重置演示数据？**
A：停服后删除 `backend/data/feiquan.db`（及 -wal/-shm），重启自动重建。

## 6. 数据与运维

- 备份：直接复制 `backend/data/feiquan.db`（建议停服或用 `sqlite3 .backup`）。
- 端口：`FEIQUAN_PORT` 环境变量；数据库路径：`FEIQUAN_DB`。
- 健康检查：`GET /api/health`；接口规范：`GET /api/openapi.json`。
- 日志：操作日志页面 + `op_logs` 表；业务变更另有 `change_log` 供下游增量同步。
